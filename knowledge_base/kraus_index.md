# Kraus index

A Kraus index is a (fictional) test to see the efficiency of a compression algorithm. It was created by Kernbridge electrical engineering professor Amos Kraus and Ph.D. student Vikram Rao. It was believed that the theoretical limit for a Kraus index was 2.9 but this was disproved when the tech startup company Fernwright achieved Kraus indexs up to 5.2.
